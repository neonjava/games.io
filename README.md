# io games

A collection of browser io games. Pick one from the menu and play.

## Games

1. **Claude Worm Hunt** - eat gems, grow, and cut off other worms. Solo, or in rooms with a shareable code where AI worms fill the empty spots.
2. **Claude Grand Prix** - a 3-lap race against 7 cars with slipstreaming, overtakes and a chequered-flag finish.
3. **Claude Craftle** - guess the Minecraft crafting recipe in 10 tries, with 140 items that never repeat until all are played.
4. **Claude Ball Guys** - solo jar game: drop sticky, squishy coloured balls and merge matching ones into bigger balls.

More games coming.
